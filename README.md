# DESIGN OF FLEXIBLE GRIPPER WITH SOLIDWORKS SOFTWARE AND PROTOTYPE WITH 3D PRINTING

📌 Overview
A mechanical design project** focused on developing a flexible gripper capable of handling varied object sizes, using SolidWorks for design and 3D printing for prototyping.

---

🛠️ Tools Used
- SolidWorks (CAD modeling and simulation)
- 3D Printer (prototyping with flexible materials)
- Basic Simulation (stress and flexibility evaluation)

---

🙋‍♂️ My Role
- Designed the flexible gripper model in SolidWorks.
- Selected material for flexibility and durability during prototyping.
- Tested grasp precision on different object geometries.
- Documented the design, testing, and results systematically.

---

📂 Files
- `Report.pdf` – Final project report with design decisions, testing results, and conclusions.
- `Photos/` – Contains design screenshots and 3D-printed gripper photos.

---

🚀 Key Features
✅ Adaptive finger design for handling multiple object sizes.  
✅ Lightweight, efficient geometry suitable for robotic arm integration.  
✅ Successfully tested for grasp stability with flexible materials.

---

📈 Future Scope
- Incorporate force sensors for feedback control.
- Develop a control system for automation.
- Optimize geometry for complex object profiles.
